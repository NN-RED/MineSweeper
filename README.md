# 🚩 Консольный Сапер на Go (Minesweeper CLI)

Минималистичная реализация классической игры «Сапер» для терминала, написанная на языке Go. Проект разработан с упором на чистую архитектуру (разделение бизнес-логики и интерфейса) и высокую производительность отрисовки без использования тяжелых графических фреймворков.

## ✨ Особенности проекта

* **Чистая архитектура:** Вся математика и логика игры инкапсулированы в изолированном пакете `internal/game` (`board.go`). Модуль отрисовки (`main.go`) ничего не знает о правилах генерации мин, он лишь отображает текущее состояние.
* **Каскадное открытие клеток:** Реализован классический рекурсивный алгоритм автоматического раскрытия пустых областей при клике на клетку с 0 мин вокруг.
* **Плавный ANSI-рендеринг:** Отрисовка интерфейса вынесена в отдельную фоновую **горутину**. Использование Esc-последовательностей `\033[H` позволяет обновлять экран без мерцания терминала.
* **Асинхронный таймер:** Независимый счетчик времени (ММ:СС), который плавно обновляется в реальном времени и не блокируется ожиданием ввода с клавиатуры.
* **Кроссплатформенность:** Игра компилируется в один независимый бинарный файл для Windows, Linux или macOS.

## 🏗️ Структура проекта
```text
├── go.mod                # Манифест Go-модуля и зависимости
├── go.sum                # Контрольные суммы (гарантия безопасности библиотек)
├── main.go               # Точка входа: инициализация, горутина рендеринга и обработка ввода
└── internal/
    └── game/
        └── board.go      # Математическое ядро игры (генерация поля, рекурсия, стейт-машина)
```

## 🎮 Управление в игре
 * Стрелочки / WASD — Перемещение курсора (⭐) по игровому полю.
 * Пробел / Enter — Открыть выбранную клетку.
 * F / f — Установить или снять флаг (🚩) на предполагаемую мину.
 * Esc — Мгновенный выход из игры.

## 🚀 Инструкция по запуску и сборке

### ТребованияRE
 * Установленный Go версии 1.18 или выше.

### Быстрый запуск для разработки:
```Bash
go run main.go
```

* Go автоматически скачает минимальную зависимость для работы с клавиатурой 
github.com/eiannone/keyboard при первом старте.

## 🛠️ Технологический стек
 * Язык: Go (Golang)
 * Параллелизм: Горутины (go func) для разделения потока отрисовки и потока ввода.
 * Интерфейс: Пакет fmt + управляющие ANSI-последовательности (смена цвета текста \033[34m, сброс \033[0m, управление кареткой \033[H).
 * Ввод: Кроссплатформенная библиотека чтения "сырых" событий клавиатуры eiannone/keyboard.
